# D1 迁移

迁移按编号只向前执行，不修改已经部署的文件：

- `0001`：人物、届次、事迹、附件与账号基础表
- `0002`：人物去向
- `0003`：账号凭据、Bearer 会话、邀请与本地虚构 fixtures
- `0004`：管理员审计、邀请撤销、本地账号标记与谱系关系 trigger
- `0005`：内容版本、持久化登录限流与邀请兑换保护

本地执行 `pnpm db:migrate:local`。生产新库执行全部迁移后，必须按 `docs/deployment.md` 显式清理虚构 fixtures，再生成并写入首位管理员。不要在已有真实数据的数据库执行 fixture 清理脚本。
