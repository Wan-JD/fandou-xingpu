# D1 迁移

迁移按编号只向前执行，不修改已经部署的文件：

- `0001`：人物、届次、事迹、附件与账号基础表
- `0002`：人物去向
- `0003`：账号凭据、Bearer 会话、邀请与人物资料字段；不写入账号或人物 seed
- `0004`：管理员审计、邀请撤销与谱系关系 trigger（历史版本曾增加本地账号标记）
- `0005`：内容版本、持久化登录限流与邀请兑换保护
- `0006`：人物资料扩展
- `0007`：精确移除历史样例 fixture，并删除旧账号标记列

本地执行 `pnpm db:migrate:local`。生产新库执行全部迁移后，再通过正式 bootstrap 脚本写入唯一超级管理员。`0007` 只匹配历史 fixture id 和历史样例邮箱；不要跳过迁移或手工恢复这些记录。
