# 翻斗星谱 brand spec

## 当前资产

- 正式名称：翻斗星谱
- 语境：翻斗花园师徒传承档案
- 官方 Logo：待用户提供；初版使用文字印记“谱”作为临时占位，不代表最终品牌资产。
- 真实人物头像、照片和附件：尚未接入，初版只使用明确标注的虚构演示资料。

## 初版设计系统

- 色彩：墨蓝 `#1E293B`、纸白 `#F7F4EC`、鼠尾草绿 `#A9BCA7`、暖金 `#C98B45`、雾蓝 `#DCE8EA`
- 字体：中文标题使用宋体/衬线风格，正文使用清晰无衬线字体
- 间距：8px 基准单位
- 圆角：卡片 16px，控件 10px，头像圆形
- 阴影：轻量层次，强调档案纸张与节点关系
- 动效：220ms ease，支持 `prefers-reduced-motion`

## 首页交互

首页整体是树谱。点击节点打开人物简介抽屉；抽屉中的“查看完整档案”进入 `/person/:id` 独立详情页。搜索会高亮匹配节点，届次可以折叠。
