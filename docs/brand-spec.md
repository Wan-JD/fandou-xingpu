# 翻斗星谱 brand spec

## 当前资产

- 正式名称：翻斗星谱
- 语境：翻斗花园师徒传承档案
- 官方 Logo：待用户提供；初版使用文字印记“谱”作为临时占位，不代表最终品牌资产。
- 真实人物头像、照片和附件：尚未接入，初版只使用明确标注的样例资料。

## 初版设计系统

- 色彩：深空 `#060A17`、星云蓝 `#102342`、星光青 `#8ED9D0`、轨道金 `#E7C982`、雾蓝 `#91B1D2`
- 字体：中文标题使用宋体/衬线风格，正文使用清晰无衬线字体；详情页沿用同一深空系统
- 间距：8px 基准单位
- 圆角：卡片 16px，控件 10px，头像圆形
- 阴影：节点使用星光 glow，简介卡使用深色半透明面板
- 动效：220ms ease，节点 hover、简介卡出现和关系线有轻量反馈，支持 `prefers-reduced-motion`

## 首页交互

整个项目使用星空主题。首页按级别分成水平轨道，同级人物在同一排；关系线从师傅连接到徒弟，跨级关系使用虚线轨迹，同级师徒用弧线连接。星谱是可缩放的画布：每个师门只在自己实际占用的轨道上占位（轮廓紧凑布局），支持拖动平移、滚轮与双指缩放、适应全图、回到起点、定位到我、全屏和缩略图导航；缩小时先隐藏标签，再只保留星点。节点卡片可以“只看这一支”或收起后辈，搜索会框选匹配的星并支持回车逐个定位。只渲染视野附近的星，几百人的谱系也能流畅拖动。点击星星节点在节点附近打开小简介卡；卡片中的“查看完整档案”会让这颗星放大铺满屏幕，再过渡到 `/person/:id` 个人主页（博客式：星座封面、身份卡、动态 / 履历 / 相册三个分区，以及简介、技能、链接、传承之路和同级星友侧栏）。组长、副组长以星冠和金 / 银环标识，与去向环相互独立；去向收敛为大厂、985研、211研、其他。徒弟管理独立为 `/students` 工作台。搜索会高亮匹配节点，级别可以折叠。
