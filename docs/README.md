# 项目文档

这里存放可提交到仓库的脱敏项目文档。任何密钥、Token、真实成员资料和数据库副本都不得放入本目录。

## 本地公测数据

本轮执行规则、数据分布、验证结果和人工清理顺序见 [本地公测记录](./public-beta-testing.md)。

在运行迁移并备份本地 D1 后，执行 `pnpm db:seed:public-beta`。脚本只使用 Wrangler `--local`，以稳定 id 追加 2022–2026 五届共 64 个带“【公测】”前缀的节点，其中 2025 级 24 人；重复执行不会删除或覆盖其他人物，也不会重置已经存在的公测账号密码。首次运行会把 3 个普通测试账号写入被 Git 忽略的 `backups/public-beta-access.json`。

本地 API 启动后，可执行 `pnpm db:seed:public-beta-content`，通过 2024 级组长测试账号追加一条横/竖/长图随手记和一条 24 图 Markdown 经验分享。脚本按标题幂等检查，不读取或输出管理员凭据。公测节点保留给人工验收；如需清理，请在管理界面从 2026 级叶节点开始，逐届向上删除。
